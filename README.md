# ✨ ZoLy — Two Little Wishes, One Endless Sky

> An enchanting interactive fairytale starring two little princesses, Zoey and Lily, each with a magical world of her own.

## 🌙 About the Project

**ZoLy** is a whimsical, interactive fairytale experience created for the **haX.baby — Baby’s First Website** hackathon.

Meet Zoey, the dreamy princess of the Crystal Kingdom, and Lily, the imaginative princess of the Aurora Kingdom. Explore their magical worlds, discover tiny surprises, and follow the story of two wishes connected by an endless sky.

Our goal is to bring the charm of the early web together with playful interactions, delightful animations, and a storybook-like experience.

## 👑 Meet the Sisters

### 🩵 Zoey — The Crystal Dreamer
A quiet, dreamy princess who creates tiny iridescent bubbles whenever she's happy.

- **World:** Crystal Kingdom
- **Magic:** Floating, shimmering bubbles
- **Theme:** Icy blue, sparkling crystals, and moonlit reflections
- **Motto:** *A little happiness, a thousand tiny bubbles.*

### 💜 Lily — The Aurora Artist
A gentle, curious princess whose imagination paints colourful auroras across the night sky.

- **World:** Aurora Kingdom
- **Magic:** Colourful ribbons of aurora light
- **Theme:** Lavender, moonflowers, and dreamy skies
- **Motto:** *Every colour begins with a dream.*

## ✨ Features

ZoLy is designed to bring its fairytale to life through interactive experiences such as:

- 🫧 **Magical Worlds** — Explore Zoey's Crystal Kingdom and Lily's Aurora Kingdom.
- 📖 **Enchanted Storybook** — Discover the sisters' shared origin story.
- 🎵 **Crystal Music Box** — A dreamy lullaby experience.
- 🗺️ **Dream Delivery Map** — Follow a magical path through their worlds.
- 🎮 **Toy Arcade** — Playful mini-game experiences.
- 🏮 **Moon Lantern** — A gentle nightlight-inspired interaction.
- 💌 **Dream Mailbox** — Share a wish or leave a little message.
- 🔮 **Secret Surprises** — Look closely for hidden magical details.
- 🌟 **Interactive Details** — Character reactions, animations, and themed controls.

*Feature availability may vary as development continues.*

## 🚀 Run Locally

### Prerequisites

- [Node.js](https://nodejs.org/) installed
- npm available in your terminal
- Git installed

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Bhavya7CSE/ZoLy.git
   ```

2. Enter the project directory:

   ```bash
   cd ZoLy
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL printed in your terminal.

### Production Build

To create a production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
